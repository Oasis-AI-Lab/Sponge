## 三、契约文档结构模板

```
契约/{板块名}-契约.md
├── 1. 定义与职责边界
├── 2. 接口（类型签名 / 方法）
├── 3. 语义（不变式 / 约束）
├── 4. 状态与生命周期
├── 5. 依赖与被依赖
└── 6. 与其他板块的交互
```

## 四、修订规则

- 任何契约的修改必须先更新契约文档，再改实现；
- 涉及固定层（04 三）的修改走契约修订流程，不随版本静默变更。
